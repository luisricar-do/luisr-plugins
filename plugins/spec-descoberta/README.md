# spec-descoberta

Leva a ideia de um software até um pacote de spec validado, sem falar de tecnologia.

| Skill | Faz |
|---|---|
| `descoberta` | entrevista em 8 blocos (sonho, pessoas, jornadas, funcionalidades, dados, regras, visual, tom), leitura de volta, fechamento e entrega (pasta ou ZIP) |
| `prototipo` | 3 direções visuais, `tokens.json` com contraste AA, design system, inventário de telas e protótipo navegável em artifact, iterado até a aprovação |

Roda no Claude Code (grava em `./spec/`) e no claude.ai (skills enviadas por ZIP; a entrega é um ZIP
para baixar). O formato do pacote está em `skills/descoberta/references/contrato-spec.md`.

Gatilhos: "tenho uma ideia de sistema", "quero criar um app", "mostra como vai ficar", "fecha o
pacote da spec".
